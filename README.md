# About Me

I'm an independent developer interested in building software, designing user interfaces, and exploring how operating systems and desktop applications work.

My work focuses on creating projects from the ground up, combining functionality, performance, and thoughtful design. Through GlozaLabs, I'm developing my own software projects, including GlozaNet and GlozaOS, while continuously learning and improving my development skills.

## What I Build

I focus primarily on desktop applications, web technologies, Linux systems, and user interface design.

I enjoy working across different parts of a project, from researching technical solutions and implementing features to refining the visual experience. My goal is to create software that is practical, efficient, consistent, and recognizable.

## Projects

### GlozaLabs

GlozaLabs is my independent development brand and the home of my software projects. It brings together my interests in application development, operating systems, interface design, and experimentation with new technologies.

### GlozaNet

GlozaNet is a custom desktop web browser built with Electron and Chromium. The project focuses on creating a modern browsing experience with a distinctive interface and features designed around usability and customization.

- JavaScript
- CSS
- Electron
- Node.js
- HTML

[Repository](https://github.com/Gloza-Labs/GlozaNet)

### GlozaOS

GlozaOS is a lightweight Linux distribution project based on existing Linux technologies, with a focus on performance, customization, and local AI.

- Debian based
- KDE Plasma 6 DE
- Custom plymouth/grub branding
- Optimized Linux kernel 6.12+deb13
